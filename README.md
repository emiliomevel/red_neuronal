# red_neuronal
Implementación de una red neuronal multicapa (MLP 4–2–3–1) para clasificación binaria en el microcontrolador NXP S32K312. Incluye código en C, entrenamiento y validación en Python, propagación hacia adelante, retropropagación, descenso de gradiente, comunicación UART y comparación de resultados entre PC y microcontrolador.
